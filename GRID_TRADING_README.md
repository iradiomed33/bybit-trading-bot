# Grid Trading Strategy - Документация

## 📊 Описание

**Grid Trading** (сеточная торговля) — стратегия для бокового рынка, которая размещает серию ордеров buy/sell на равномерных уровнях в диапазоне консолидации. Извлекает прибыль из каждого колебания цены между уровнями сетки.

## 🎯 Когда использовать

- ✅ Боковой рынок (консолидация, range)
- ✅ Низкая волатильность с предсказуемыми колебаниями
- ✅ ADX < 25 (отсутствие сильного тренда)
- ✅ Ширина Bollinger Bands в нормальных пределах (0.015-0.05)

**Текущая ситуация (февраль 2026):** Оптимальна! Рынок в фазе консолидации после коррекции.

## ⚙️ Настройки в bot_settings.json

```json
"GridTrading": {
  "enabled": true,
  "confidence_threshold": 0.70,
  "range_mode": "auto",              // auto или manual
  "range_lookback": 100,              // Период для определения диапазона
  "grid_levels": 20,                  // Количество уровней сетки
  "grid_spacing_percent": 1.5,        // Шаг между уровнями (%)
  "require_ranging_market": true,     // Проверять боковое движение
  "max_adx_for_range": 25.0,         // Макс. ADX для range
  "min_bb_width": 0.015,             // Мин. ширина BB
  "max_bb_width": 0.05,              // Макс. ширина BB
  "enable_breakout_protection": true, // Защита от пробоя
  "breakout_volume_threshold": 2.0,   // Z-score объёма для пробоя
  "stop_loss_atr_multiplier": 3.0,   // SL за границами диапазона
  "profit_per_grid": 1.5,            // Целевая прибыль на уровень (%)
  "max_grid_positions": 5,           // Макс. открытых позиций
  "rebalance_on_drift": true,        // Пересчёт при смещении
  "drift_threshold_percent": 10.0    // Порог смещения для ребаланса
}
```

## 🚀 Как работает

### 1. Определение диапазона
- **Auto mode:** Автоматически определяет min/max цен за последние N баров
- **Manual mode:** Используются ручные границы (для точной настройки)

### 2. Генерация сетки уровней
- Создаёт равномерные уровни buy/sell в диапазоне
- Шаг между уровнями = `grid_spacing_percent` (рекомендуется 1-2%)
- Пример: при BTC $65k-$75k и шаге 1.5% → ~20 уровней

### 3. Фильтры входа
Проверяет условия бокового рынка:
- **ADX < 25** — низкий тренд
- **BB width 0.015-0.05** — умеренная волатильность
- **Volume Z-score** — нет аномальных всплесков

### 4. Генерация сигналов
- **LONG** у уровней поддержки (нижние уровни сетки)
- **SHORT** у уровней сопротивления (верхние уровни сетки)
- **Take Profit** = следующий уровень сетки
- **Stop Loss** = за границами диапазона (3 ATR)

### 5. Защита от пробоя
Останавливает торговлю при:
- Высоком объёме (Z-score > 2.0)
- Резком движении цены (>2% за бар)
- Цене близко к границам диапазона

### 6. Ребалансировка
При смещении диапазона >10% автоматически пересчитывает сетку.

## 💡 Пример работы

```
Диапазон: $67,000 - $73,000
Сетка (20 уровней, шаг 1.5%):

$73,000 ← Верхняя граница
$71,900 ← SHORT (у сопротивления)
$70,800
$69,700
$68,600 ← Текущая цена
$67,500 ← LONG (у поддержки)
$67,000 ← Нижняя граница

Логика:
1. Цена падает до $67,500 → LONG сигнал
2. Бот покупает, TP на $68,600 (следующий уровень)
3. Цена растёт до $68,600 → закрывает с прибылью
4. Повторяется для каждого колебания
```

## 🌍 Работа с несколькими парами

Grid Trading **работает независимо для каждой пары**:

```json
"trading": {
  "symbols": [
    "BTCUSDT",   // Своя сетка $65k-$75k
    "ETHUSDT",   // Своя сетка $2.0k-$2.5k
    "SOLUSDT",   // Своя сетка $XX-$YY
    "XRPUSDT"    // Своя сетка $XX-$YY
  ]
}
```

Каждый символ получает:
- ✅ Собственный диапазон (auto detection)
- ✅ Независимую сетку уровней
- ✅ Отдельное состояние (позиции, ребалансировка)

## 🛠️ Ручная настройка диапазона

Для точного контроля используйте manual mode:

```json
"GridTrading": {
  "range_mode": "manual",
  "manual_lower": 65000.0,  // нижняя граница для BTC
  "manual_upper": 75000.0   // верхняя граница для BTC
}
```

⚠️ **Важно:** Manual mode применяется ко всем символам. Для разных границ по парам используйте auto mode.

## 🎓 Теория Grid Trading

Grid Trading основана на принципе **mean reversion** — цена стремится вернуться к среднему значению в диапазоне. В отличие от других стратегий:

- **TrendPullback** → ловит откаты в тренде
- **Breakout** → ловит пробои диапазона
- **MeanReversion** → ловит возврат к среднему
- **GridTrading** → ловит ВСЕ колебания в диапазоне 🎯
